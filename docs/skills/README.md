# Harbor AI skills

Load the smallest relevant skill set before a task. Skills supplement, but never
override, repository instructions or approved specifications.

- [Documentation](documentation.skill.md)
- [Architecture](architecture.skill.md)
- [Feature planning](feature-planning.skill.md)
- [Database](database.skill.md)
- [API](api.skill.md)
- [Provider](provider.skill.md)
- [React](react.skill.md)
- [Testing](testing.skill.md)
- [Security](security.skill.md)
- [Review](review.skill.md)

Recommended combinations:

| Task                | Skills                                                    |
| ------------------- | --------------------------------------------------------- |
| Feature design      | Documentation + Feature planning + relevant domain skill  |
| Database change     | Database + Security + Testing                             |
| Provider capability | Provider + Security + Testing                             |
| React page          | React + Feature planning + Testing                        |
| Review              | Review + Architecture/Security/domain skill as applicable |
