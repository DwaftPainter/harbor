# Prompt — Generate a React page

```text
Build one approved Harbor page or page increment.

Route and user outcome: [route/outcome]
Approved feature/UI contract: [links]
Data and permissions: [contract]
Required states: loading, empty, stale, partial, error, forbidden, not found,
success
Accessibility/performance criteria: [criteria]

Load docs/skills/react.skill.md, frontend architecture, folder, testing,
security, and Definition of Done standards. Use Server Components by default.
Create the narrowest possible client boundary. Keep business behavior in the
feature/application service, make URL state shareable, and use existing shadcn
and shared components where appropriate.

Do not add demo data, client-side authorization, global state, or speculative UI
abstractions. Verify keyboard/focus/semantic behavior, responsive states, bundle
impact, and tests. Report screenshots/manual evidence where requested.
```
