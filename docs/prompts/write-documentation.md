# Prompt — Write documentation

```text
Create or update Harbor documentation for [topic].

Document type/status/owner: [details]
Source evidence: [approved docs, decisions, current behavior]
Target phase/features: [links]
Required sections and reviewers: [details]

Load docs/skills/documentation.skill.md and the relevant domain skill. Use Harbor
terminology, relative links, explicit current/future/out-of-scope separation, and
testable behavior. Cover permissions, data ownership, API/UI, validation,
failures, edge cases, security, testing, telemetry, migration, recovery, and open
questions as applicable.

Do not mark a document Approved/Implemented without authority and evidence, copy
vendor text, invent behavior, or conceal contradictions. Report created/updated
documents, unresolved questions with owners, required ADRs, and link/format
validation.
```
