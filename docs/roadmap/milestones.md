# Project milestones

Status: Draft

| Milestone                      | Included phases | Exit outcome                                                                        |
| ------------------------------ | --------------- | ----------------------------------------------------------------------------------- |
| M0 — Governed repository       | 00–01           | Documentation gates, quality checks, environments, and deployment baseline exist    |
| M1 — Secure tenancy            | 02–04           | Identity, organizations, roles, permissions, and audit events are enforceable       |
| M2 — Connected inventory       | 05–07           | At least one provider syncs read-only resources reliably into an isolated inventory |
| M3 — Application control plane | 08–10           | Applications, environments, deployments, and configuration metadata are navigable   |
| M4 — Daily operations          | 11–13           | Dashboard, search, notifications, and GitHub context support operational workflows  |
| M5 — Automation preview        | 14–15           | Background operations and versioned API access are controlled and observable        |
| M6 — Production readiness      | 16              | Security, recovery, performance, accessibility, and operational launch gates pass   |

## Milestone acceptance

A milestone is complete only when:

- all included phase checklists are complete;
- feature and architecture documents say `Implemented`;
- automated verification and documented manual acceptance pass;
- security and observability requirements are demonstrated;
- operational ownership and rollback procedures are assigned;
- deferred items are recorded, prioritized, and do not invalidate the outcome.
